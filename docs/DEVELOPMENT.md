# Local Development Guide

## Prerequisites
- Node.js >= 20.x
- npm >= 10.x
- PostgreSQL >= 14 (optional for local in-memory fallback mode)

## Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Build TypeScript workspaces
npm run build

# 3. Start API Gateway Engine
npm run dev

# 4. Open Frontend
# Open frontend/src/index.html in browser or host via static web server on port 4200
```
